立场

ADPS 共同体对 Agent 工程中若干争议话题的立场专文。每一篇都给出明确、以证据为据的判断——我们持什么立场、为什么、边界在哪。

  • 多 Agent 何时该用
    多 Agent 是矩阵中有明确边界的设计选择。单 Agent、工具集与 Harness 应先建立可比较的生产基线。
  • Prompt Engineering 的位置
    Prompt 负责模型调用中的语言层控制；系统边界由 Harness 的状态、工具、权限和验证机制共同决定。
  • 治理与 Safety
    治理进入运行时设计：权限、审计、影响范围和自主权升级都需要明确的工程控制。
  • Eval 的工程化
    Evaluation 贯穿设计、上线前验证和生产运行，为模式选型、发布与回滚提供证据。
