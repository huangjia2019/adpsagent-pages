袁良锭（Liangding Yuan）

研究报告 03 · MBSE / SysML · 建模 Agent

成都的架构师和个人研究者，拥有十六年研发与架构经历，做过流程、搜索、协作、授权和知识系统等平台工作。当前通过个人技术站点 mbse.ltd 记录 AI 辅助 MBSE / SysML 的学习、推演和本地实验。

研究报告：自然语言到 SysML：单图写回的建模 Agent 研究。报告记录元素、关系和视图的类型化中间表示，以及范围解析、写回门禁、可恢复澄清和事务回执。

资料说明：报告中的身份、机构与实现信息由各贡献者提供。ADPS 收录这些资料用于技术讨论，未对相关产品做独立评测。
