袁良锭（Liangding Yuan）

研究报告 03 · MBSE / SysML · 建模 Agent

成都的架构师和个人研究者，拥有十六年研发与架构经历，做过流程、搜索、协作、授权和知识系统等平台工作。当前通过个人技术站点 mbse.ltd 记录 AI 辅助 MBSE / SysML 的学习、推演和本地实验。Ark 与 AI4MBSE 均为个人研究项目代号，不对应实体企业或经营机构。

研究报告：自然语言到 SysML：单图写回的建模 Agent 研究。报告记录元素、关系和视图的类型化中间表示，以及范围解析、写回门禁、可恢复澄清和事务回执。
