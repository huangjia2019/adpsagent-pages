团队

ADPS 由创始成员、顾问、专家组和蓝皮书贡献者共同维护。本页列出每位成员的公开背景、工作范围与案例贡献。

创始成员

黄佳（Jia Huang） 简历 PDF

Agent 架构 · 模式语言 · 工程教育

新加坡 A*STAR AI 研究员，Manning 《Designing AI Agents》作者。同时著有《Agent 设计模式》，并主讲极客时间《Claude Code 工程化实战》课程。研究范围包括 Agent 职责边界、执行拓扑、验证机制与长程任务可靠性。

在 ADPS 的工作：共同提出“认知功能 × 执行拓扑”双轴框架，维护模式目录、选型方法、中英文白皮书与企业案例体系。

茹炳晟（Bingsheng Ru）

软件工程 · 智能体系统 · 研发效能

腾讯研究院产业研究顾问，中国计算机学会 CCF TF 多智能体系统工程 SIG 副主席，复旦大学 Codewisdom 首席技术专家。长期从事软件工程、智能体系统、研发效能与 AI 辅助开发的产业研究和技术传播。

在 ADPS 的工作：从软件复杂性、研发效能、组织协作和工程评测角度审视模式定义与适用边界。

姜宁（Willem Jiang）

开源基础设施 · 系统集成 · 工作流

Apache 软件基金会长期贡献者，Apache Camel 社区成员。公开资料记录了他对 DeerFlow 2.0 相关活动的参与，个人公开资料标注为 DeerFlow developer。

在 ADPS 的工作：负责开源基础设施、系统集成与可运行工作流的工程对照，重点关注路由、编排、事件流和社区协作。

梁博（Bo Liang）

企业 SaaS · 金融服务 · 生产系统

上海东方屹腾科技有限公司副总裁、创办期股东与合伙人，负责技术和产品。东方屹腾聚焦银行泛金融生态 SaaS 服务；其薪享通 SaaS 服务矩阵已与 20+ 银行建立联合运营体系，服务 5 万+ 企业客户。

在 ADPS 的工作：提供金融服务、HR SaaS、薪酬、考勤、个税和薪资代发等流程中的部署证据，并记录 SaaS 产品向执行型 Agent 转型时的状态、授权与可观测性问题。

顾问

周天异（Joey Tianyi Zhou）

专家组

王昊奋

知识图谱 · 知识增强大模型 · 知识工程

同济大学长聘教授、博士生导师，研究知识图谱与知识增强大模型。公开成果包括 OpenSPG、KAG-Thinker、MemOS 和 AI-Ceping，相关工作已用于机场调控、金融风控与座舱交互等场景。近五年出版学术专著 3 部，以第一或通讯作者身份发表论文 45 篇，谷歌学术引用超过 1.27 万次。

在 ADPS 的工作：知识工程，以及可导航、可查询的模式知识体系。

张海立

LangChain Ambassador · 开源实践 · 参考实现

《LangGraph 实战》《LangChain 实战》作者，LangChain 官方大使，LFAPAC 开源布道师，长期从事 GenAI、云原生与开源技术的实践与传播。

在 ADPS 的工作：将模式语言映射到 LangChain 与 LangGraph 可运行参考实现。

工程教学 · 云架构师社区

在 ADPS 的工作：工程教学和企业架构师社区中的模式评审、案例传播与实践反馈。

案例报告 01 · 企业 SaaS · 执行型 Agent

上海东方屹腾科技有限公司副总裁，同时是 ADPS 创始成员。

熊钰柯（Yuke Xiong）

案例报告 02 · 地理信息 · 数据发布 Agent

玄宿科技技术架构师、创业合伙人，长期从事 GIS 软件产品与项目交付，当前聚焦将 Agent 能力接入企业级业务系统。

袁良锭（Liangding Yuan）

案例报告 03 · MBSE 与工业软件 · 建模 Agent

Ark · 雅格创始人，成都。拥有十六年工业软件与平台研发经验，曾从事流程、搜索、协作与知识系统开发，当前聚焦 AI 辅助 SysML / MBSE 产品化。

案例报告：自然语言到 SysML：一张图交付的建模 Agent。报告记录元素、关系和视图的类型化中间表示，以及范围解析、写回门禁、可恢复澄清和事务回执。
