ADPS 企业 Agent 系统蓝皮书

工程概念目录

从具体案例中提炼，用于比较 Agent 系统的工程语言。

这个目录不要求读者先懂行业术语。请先按案例阅读：看懂任务、失败和交付结果，再进入单个概念页。

“案例命名”来自具体实践；“ADPS 重述”借助既有软件工程语言重新界定；“候选概念”还需要更多独立案例验证。

东方屹腾 · 长程执行型 Agent

薪酬配置跨越多个依赖步骤。系统要保住原目标、当前进度、参数来源和审批位置。 先读案例报告

  • 控制平面与叙事平面 — 控制信号驱动程序分支，叙事上下文为模型推理提供语义输入。
  • 执行型与内容生成型 Agent — 按交付对象、状态依赖和错误成本选择运行时机制。
  • 会话统一状态：三个状态平面 — SessionNarrative、SessionState 和 Workspace 分别管理语义、参数与调度。
  • 机械状态平面与 Provenance 来源坐标 — 业务参数由程序按来源坐标传递，不经模型重新生成。
  • 锚、账、集：叙事状态的数据结构 — Anchor 保存目标，Ledger 追加事实，Collection 提供当前读取视图。
  • 草稿纸看板：Agent 的短期工作面 — 用结构化字段保存当前目标、步骤、观察、阻塞、证据和下一动作。
  • 记忆信封：推理步骤的上下文包 — ReasonContext 按步骤组装目标、进展、意图结论和相关经验。
  • L1/L2/L3 分层记忆与经验召回 — 当前输入、任务事实和跨任务经验分层存储，完整事实按引用加载。
  • Orchestrator 与 MessageHandler 的职责边界 — Orchestrator 管理控制流，MessageHandler 负责输入适配和流式呈现。
  • 意图编译：从自然语言到控制信号 — 入口分类器输出有限枚举，异常结果进入 unknown 兜底。
  • 任务 DAG 与节点状态机 — 依赖边限定执行顺序，节点状态支持调度、验收和恢复。
  • 可观测性：活动事件与执行时间线 — Activity 与 Frame 关联模型、工具、状态变化、耗时和成本。
  • HITL：阻塞、审批与恢复 — 敏感节点暂停并保存状态，审批后重新校验并继续执行。

玄宿科技 · GIS 数据发布 Agent

一份地图数据要经过处理、发布和用户侧验收。内部日志报成功，不代表用户已经看到结果。 先读案例报告

  • 推理资产化 — 设计期形成可审阅、可认证的能力资产，运行期消费指定版本。
  • 磁盘事实平面 — 以版本化外置合同承载阶段事实、运行状态和验收证据。
  • 外部验收探针 — 从用户一侧发出真实请求，以状态、内容和可见结果裁决成功。
  • 失败到规则闭环 — 事故卡回链规则、默认值、约束或测试，并由后续同类任务验证。
  • 能力认证生命周期 — 能力按 draft、candidate、active 逐步取得运行权，版本漂移后自动失效。

AI4MBSE · 个人研究项目

自然语言最终要改动共享的工程模型。动手之前，系统必须先说清对象、关系、写入范围和验收条件。 先读案例报告

  • 类型化中间表示链 — 自然语言逐段收敛为可验证、带类型和稳定引用的候选结构。
  • 单图事务 — 一种图、一个已解析范围、一次写入和一份回执构成提交边界。
  • 结构写回门禁 — 候选结构通过范围、类型、引用、完整性和真实增量检查后才能写入。
  • 可续跑澄清作业 — 缺少信息时冻结同一作业，保存已确认字段、候选项和恢复游标。
  • 词表等价层 — 以版本化映射对齐规划词表、领域类型和宿主元模型。
