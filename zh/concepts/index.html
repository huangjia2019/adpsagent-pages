范围：收录表示该术语有工程解释价值，不表示它已经成为行业标准。

本目录定义 ADPS 案例报告中使用的工程术语。每个条目说明机制、对应的失败方式与适用条件。当前定义源于 东方屹腾执行型 Agent 案例报告，在获得更多独立案例印证前保持“案例衍生”状态。

  • 控制平面与叙事平面 — 控制信号驱动程序分支，叙事上下文为模型推理提供语义输入。
  • 执行型与内容生成型 Agent — 按交付对象、状态依赖和错误成本选择运行时机制。
  • 会话统一状态：三个状态平面 — SessionNarrative、SessionState 和 Workspace 分别管理语义、参数与调度。
  • 机械状态平面与 Provenance 来源坐标 — 业务参数由程序按来源坐标传递，不经模型重新生成。
  • 锚、账、集：叙事状态的数据结构 — Anchor 保存目标，Ledger 追加事实，Collection 提供当前读取视图。
  • Scratchpad：ReAct 的工作记忆 — Thought、Action 和 Observation 以 block 形式追加，供下一轮读取。
  • 记忆信封：推理步骤的上下文包 — ReasonContext 按步骤组装目标、进展、意图结论和相关经验。
  • L1/L2/L3 分层记忆与经验召回 — 当前输入、任务事实和跨任务经验分层存储，完整事实按引用加载。
  • Orchestrator 与 MessageHandler 的职责边界 — Orchestrator 管理控制流，MessageHandler 负责输入适配和流式呈现。
  • 意图编译：从自然语言到控制信号 — 入口分类器输出有限枚举，异常结果进入 unknown 兜底。
  • 任务 DAG 与节点状态机 — 依赖边限定执行顺序，节点状态支持调度、验收和恢复。
  • 可观测性：活动事件与执行时间线 — Activity 与 Frame 关联模型、工具、状态变化、耗时和成本。
  • HITL：阻塞、审批与恢复 — 敏感节点暂停并保存状态，审批后重新校验并继续执行。
