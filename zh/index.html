Agent Design Patterns Society

面向生产级 Agent 系统的公共模式语言。

ADPS 是一个独立研究共同体，为生产级 Agent 系统的构建提供公共技术参考。 我们汇集软件设计研究、开源 Harness 工程实践和具名企业案例，把其中的共性架构问题整理成 可复用的模式规范，供工程团队选用。

28 个核心模式矩阵 · 7 个认知功能 × 6 种执行拓扑

我们做什么

ADPS 维护四类相互关联的公共技术资料：

  • 模式白皮书与模块总纲——定义问题、机制、适用条件、失效方式与验证标准。
  • 工程蓝皮书——记录具名系统的约束、失败、架构决策和可迁移边界。
  • 研讨会与专题——保留业界讨论，并整理跨模块的工程方法。
  • 开放参考资产——论文、选型方法、实现示例与工程概念。

框架

双轴框架——认知功能 × 执行拓扑——首次发表在论文 A Two-Dimensional Framework for AI Agent Design Patterns（Huang & Zhou， arXiv:2605.13850）， 并在 Manning 的英文书 Designing AI Agents 中进一步展开。ADPS 现在作为共同体资产持续维护这套目录。

蓝皮书实践

三份报告分别记录企业 SaaS、GIS 数据发布和 MBSE / SysML 研究中的具体架构选择。

  • 东方屹腾执行型 Agent ——任务 DAG 固定执行顺序，机械状态平面管理参数来源，checkpoint 支持中断恢复。
  • 玄宿科技 GIS 数据发布 Agent ——设计期把推理整理成版本化资产，运行期走确定性管线，发布结果再由外部验收探针检查。
  • 自然语言到 SysML ——类型化中间表示承接自然语言，范围解析与结构写回门禁在入库前阻断歧义，操作结束后返回事务回执。
