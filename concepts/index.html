Intent as Compilation

Translate open language into a validated, bounded control signal with an explicit fallback.

Task DAG and State Machine

Make dependencies, node status, acceptance, and recovery explicit.

Reasoning Assetization

Move repeated, reviewable decisions into versioned capability assets before runtime.

Typed IR Chain

Narrow natural language through typed, verifiable structures before write-back.

One-Diagram Unit of Work

Commit one diagram, one resolved scope, one write set, and one receipt at a time.

Structural Write-Back Gate

Check scope, types, references, completeness, and real change before side effects.

Resumable Clarification Job

Pause the same durable job when one required field is missing, then resume it.

Vocabulary Equivalence Layer

Align planning terms, domain types, and the host metamodel through one tested mapping.

Plan Compilation

Compile a reasoned plan into an executable structure with dependencies, types, authority, and acceptance.

Collaboration and runtime control6

Topology Lowering

Compile high-level collaboration semantics into runtime primitives such as serial, parallel, and routing edges.

Topology Governance Matrix

Review serial, parallel, and routed structures across identity, authority, safeguards, and provenance.

Handoff Contract

Transfer goal, artifacts, decisions, authority, responsibility, and acceptance together.

Three Collaboration Planes

Review Agent-Agent, Human-Agent, and Human-Human collaboration around the system.

Hook Composition

Compose orchestration, governance, observation, and recovery at lifecycle events.

Write-Conflict Domain

Identify files, identifiers, configuration, domain objects, and environments that concurrent tasks may jointly mutate.

Evaluation, reflection, and governance10

Activity Events and Timeline

Record model, tool, state, latency, cost, and external results on one execution timeline.

HITL Block and Resume

Persist a protected execution point, revalidate it, and resume the same action after review.

External Acceptance Probe

Test the result from the user side and let that evidence decide success.

Failure-to-Rule Loop

Require every repeated failure to change a rule, test, template, or capability asset.

Capability Certification Lifecycle

Grant automatic execution rights only to a tested capability version and scope.

Dual Feedback Clock

Separate immediate within-run feedback from delayed cross-run outcomes.

Durable Intent

Keep approval wait and resumed execution bound to the same immutable action.

Three Powers of Agency

Inspect agent power at the points of information, judgement, and action.

Judge Migration

Track how acceptance authority moves across requirements, tests, review, deployment, and outcomes.

Dual-Scale Governance

Govern the current action and the long-running goal at the same time.
